# 黑屁屁的房間

互動紀念貓咪遊戲。部署檔案位於 dist/。

逐格嘴巴咬住點追蹤、五種玩具、坐墊中央休息、平滑肚肚膚質及彩色功能圖示。

## 專案移交與本機啟動（2026-10-30）

此完整專案包含 dist/ 中實際使用的圖片、七支電視影片、音效，以及可編輯的 JavaScript、CSS、HTML。tests/ 是行為回歸檢查，docs/ 保留設計與開發紀錄，ASSET-LICENSES.md 記錄素材來源。

1. 安裝 Node.js（建議 22 或更新版本）。
2. 解壓縮後，在本資料夾開啟終端機，執行：node preview-server.mjs --host 127.0.0.1 --port 4173
3. 瀏覽器開啟 http://127.0.0.1:4173/ 。請使用伺服器，不要直接雙擊 index.html，因為素材載入需要 HTTP。
4. 修改 dist/room.js（主要遊戲）、dist/room-layout.js（配置）、dist/window-scene.js（窗景）等原始碼，重新整理即可。

此專案不需要安裝 npm 套件即可啟動。瀏覽器內的個人遊戲進度存在該瀏覽器的 localStorage，並不包含在 ZIP 中。天氣資料需要網路，無法連線時使用既有備援顯示。ZIP 不含 Git 登入憑證或 .git 歷史；.openai/hosting.json 僅保留既有網站的部署設定，另建網站時請使用自己的部署設定。
