# 窗景與窗簾動畫重製設計

保留台灣住家、原白色雙開窗、房間與貓咪互動。以竹圍當地日期、太陽高度、月相與即時天氣驅動同一套光線。取代原本在白天背景上套遮罩的作法。

## 採用方向
分層窗景與獨立布料：天空、雲、遠山、台灣住宅、樹冠、雨、玻璃水滴、窗框、紗簾、厚窗簾。各層獨立繪製，共用光源。固定白天照片加色罩會保留白天細節；預錄影片難以組合日期與天氣；因此建議分層即時動畫。

## 時段
- 日出前：靛藍天空逐漸泛紫，街屋少量暖燈，紗簾微弱透光。
- 日出：地平線粉橘，雲邊暖光，紗簾靠窗一面受光，摺痕維持立體。
- 上午至正午：天空淡藍至清藍，雲影緩慢移動，厚窗簾仍是米色，紗簾明亮但不發白。
- 下午：光源位置改變，樹影與窗簾明暗方向同步。
- 夕陽：低處金橘、上方灰紫，住家燈光逐步亮起。
- 入夜：天空、山、住家各自轉暗，避免整片黑色矩形。
- 月夜：依月相與月球高度顯示月亮，受雲量影響；窗簾保留室內暖光與窗外冷光，不整片變藍或灰。

## 天氣動畫
晴天有稀薄移動雲；多雲有不同速度的雲層；陰天光線柔和、遠山對比降低。
毛毛雨是細密短雨絲及緩慢累積的小水珠；一般雨是前後兩層斜雨及玻璃水滴滑落；大雨增加雨幕、風偏與遠景霧化。
雷雨使用不等間隔、有分支的遠方閃電，雲層短暫被照亮，紗簾與窗框同步受光；不以全畫面白色閃爍代替。減少動態偏好時停用閃光。
霧以遠山與建物的距離分層淡化。雪與冰雹只在天氣資料回報時呈現，不能因冬季就讓竹圍下雪。

## 季節
春季較嫩的常綠樹冠與柔和光色；夏季濃綠、日照較長；秋季偏橄欖綠並少量暖葉；冬季偏冷、日照較短。維持台灣常綠景觀，不使用整片歐美紅葉或冬季光禿樹。日出日落由日期計算，季節只影響景觀細節。

## 窗簾
移除包含原白天窗景的矩形裁切。布料輪廓、摺痕、透光與光源分離；紗簾後方必須透出同一份動態窗景。窗戶關閉時僅極輕微布料起伏，不因室外暴雨而在室內劇烈飄動。

## 驗收
逐一檢查四季的日出、正午、夕陽與午夜，並交叉檢查晴、陰、毛毛雨、大雨、雷雨、霧。檢查兩片玻璃、兩側紗簾、窗框邊緣無白天殘留、矩形接縫與色差；手機直橫向一致。實際天氣與示意動畫需區分，資料失效時顯示暫不可用，不捏造晴天。既有貓咪、動線、集合與鏡頭功能不變。
